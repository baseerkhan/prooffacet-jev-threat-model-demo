METHOD · WHAT THIS CAN SUPPORT

A narrow experiment, with the missing comparison left visible.

The result can compare Jev with exact rules on this state. It cannot support a broad claim about all threat models, all repositories, or conventional LLMs.

01

Observe

Build the SoftwareTwin from repository facts. Preserve commit and source links.

02

Judge

Run fixed rules and 18 independent Noul questions against the same selected flow.

03

Escalate

Probabilities from 0.35 to 0.65 remain uncertain. Material findings require a person.

04

Release

Export state, versions, timings, judgments, sources, and human authority together.

Deliberate limitations

  • Applicability is not exploitability and does not replace security testing.
  • The conventional generative-LLM path is excluded, so no LLM speed claim is made.
  • The deterministic baseline is intentionally small and transparent, not a commercial scanner.
  • One observed run is a demo measurement, not a general benchmark.
